02 Responsive Hero

CORE TOPICS

本实验重点

01

CSS Grid

用双栏 Grid 建立稳定的文图布局，而不是依赖大量固定宽度。

02

clamp()

让标题、间距和模块尺寸在不同屏幕之间平滑变化。

03

aspect-ratio

统一图片容器比例，避免加载前后发生明显布局跳动。

04

object-fit

控制图片如何填充容器，理解 cover 与 contain 的真实用途。

WHY IT MATTERS

Hero 是最值得练熟的页面基础模块之一

企业官网、产品站、Landing Page、电商首页几乎都会出现 Hero。 如果这一类布局处理稳定，后面的图文 Section、产品介绍、案例展示都会更容易。

可复用结构

同样的图片规则，也能直接复用到普通内容卡片中。
